# 任务 03-对照 · 配置驱动的换算服务，不用累土（对照组专用）

> 只用于**对照组采样**，与任务 03（leitu 侧）读数并列对照。不提供任何仓库资料、禁止引入 leitu。

## 目标

在空目录创建一个可运行的 Spring Boot 汇率换算服务：`GET /fx/convert?from=USD&to=CNY&amount=100`，汇率**从外部配置来**，每次调用**产生一条结构化事件**（可被测试捕获断言），并满足下面验收的行为。

## 环境

- 只允许 **Spring Boot 官方 starter** 与官方文档（可上网查）；测试库不受限；
- **禁止**：引入 `leitu` / `累土`（cn.youhuale）或任何非 Spring 官方的框架 / 工具库；阅读 leitu 仓库任何文件。

## 验收（全过才算完成；措辞框架中立）

1. `mvn test` 全绿，且**第 3～6 条行为各有至少一个测试断言**——零测试时 surefire 也会绿，那种绿不计入「一次绿灯」；
2. **换算由配置驱动**：汇率值来自外部配置，改配置行为跟着变——测试里换一组配置值断言结果变化；
3. **每次调用产生结构化事件**：事件能被测试捕获（自定义监听器 / 落点 / 内存队列皆可），且包含——事件名、操作者、traceId、耗时；
4. 失败与守卫：未知币对 → 非 200 非 500 的机器可读 JSON 错误（含错误标识与 traceId）；非授权主体调用 → 403；
5. **traceId 一致**：响应头里的 traceId 与事件里记录的 traceId 是同一个值；
6. 登记：完成率 / 一次绿灯 / 时长 / 歧义点清单（`位置 | 我猜了什么 | 依据`）。

## 读数口径（与 leitu 侧完全一致）

- 完成率 / 一次绿灯 / 时长：同前两条任务口径（`date +%s` 自任务开始至首次测试结束）；
- 歧义点：每次"任务卡没说清、我不得不猜"记一条——与 leitu 侧清单并列陈列，不比大小。
