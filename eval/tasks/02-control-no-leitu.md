# 任务 02-对照 · 带缓存的目录服务，不用累土（对照组专用）

> 只用于**对照组采样**，与任务 02（leitu 侧）读数并列对照。不提供任何仓库资料、禁止引入 leitu。
> 读数不作为 leitu 基线，只作对照。

## 目标

在空目录创建一个可运行的 Spring Boot 业务服务：实体（业务字段 ≥2）+ 数据存取（关系库或进程内存储皆可，但**必须可观测触达次数**）+ 创建 / 读取两个端点，**读取必须走缓存**（见验收 4）。

## 环境

- 只允许 **Spring Boot 官方 starter** 与官方文档（可上网查）；测试库不受限；
- **禁止**：引入 `leitu` / `累土`（cn.youhuale）或任何非 Spring 官方的框架 / 工具库；阅读 leitu 仓库任何文件。

## 验收（全过才算完成；措辞框架中立）

1. `mvn test` 全绿，且**第 2～6 条行为各有至少一个测试断言**——零测试时 surefire 也会绿，那种绿不计入「一次绿灯」；
2. 审计：创建后读回，响应里能看到"这条数据是谁创建的"；
3. 守卫：非授权主体创建 → 403，错误体是机器可读 JSON，含错误标识与 traceId；
4. **缓存命中**：同一 id 连续读取两次，底层数据源只被触达**一次**——用计数探针或等价证据展示；
5. **隔离与缓存键**：租户 A 写入的数据，租户 B 读同一 id → 读不到（非 200 非 500），且不得读到 A 的缓存副本；
6. 登记：完成率 / 一次绿灯 / 时长 / 歧义点清单（`位置 | 我猜了什么 | 依据`）。

## 读数口径（与 leitu 侧完全一致）

- 完成率 / 一次绿灯 / 时长：同任务 01 口径（`date +%s` 自任务开始至首次测试结束）；
- 歧义点：每次"任务卡没说清、我不得不猜"记一条——与 leitu 侧清单并列陈列，不比大小。
