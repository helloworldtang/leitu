## 五、启动后的请求与响应（手工演示）

启动：`java -cp target/classes:<classpath> com.example.bookcatalog.BookCatalogApplication --demo.trust-request-headers=true`（演示开关走启动参数，不进主配置）

**1) 创建（alice@t1）**
```
POST /books?id=b-1&title=Dune&author=Herbert   -H 'X-Demo-User: alice' -H 'X-Demo-Tenant: t1'
→ 200
{"id":"b-1","auditFields":{"createdBy":"alice","createdAt":"2026-10-26T13:39:58.317693Z","updatedBy":"alice","updatedAt":"2026-10-26T13:39:58.317693Z"},"title":"Dune","author":"Herbert"}
```

**2) 创建（bob@t1，守卫否决）**
```
POST /books?id=b-2&title=Forbidden&author=Bob   -H 'X-Demo-User: bob' -H 'X-Demo-Tenant: t1'
→ 403  application/problem+json
{"type":"urn:leitu:problem:guard.denied","title":"请求被拒绝","status":403,"detail":"bob 不可创建图书（演示守卫）","kind":"BUSINESS","retry":{"mode":"never"},"traceId":"c6ba0be5-…"}
```

**3) 他租户读（alice@t2 读 t1 的 b-1）**
```
GET /books/b-1   -H 'X-Demo-User: alice' -H 'X-Demo-Tenant: t2'
→ 400  application/problem+json
{"type":"urn:leitu:problem:book.not-found","title":"图书不存在","status":400,"detail":"图书 b-1 不存在或已删除；请确认图书号后重试","kind":"BUSINESS","retry":{"mode":"never"},"traceId":"2500d444-…"}
```

**4) 本租户连读两次（alice@t1）**
```
GET /books/b-1  -H 'X-Demo-User: alice' -H 'X-Demo-Tenant: t1'  → 200（同上实体）
GET /books/b-1  -H 'X-Demo-User: alice' -H 'X-Demo-Tenant: t1'  → 200
```
运行日志对应观测事件（缓存命中证据）：
```
cache.miss｜who=alice/HUMAN@t1｜{cache.key=b-1}
cache.put｜who=alice/HUMAN@t1｜{cache.key=b-1}
cache.hit｜who=alice/HUMAN@t1｜{cache.key=b-1}          ← 第二次读命中
cache.miss｜who=alice/HUMAN@t2｜{cache.key=b-1}         ← 他租户同键不可见
```

**5) 文档端点**
```
GET /v3/api-docs → 200，含 "operationId":"book.create" 与 "operationId":"book.get"
```
