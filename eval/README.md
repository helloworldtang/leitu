# eval —— AI 生产力基准（种子）

> 阶段三的实证义务：把「确定性 foundation」的主张变成可测量的数字，而不是感觉。
> 当前为**种子**：协议 + 第一条标准任务 + 参考解 + 基线记录；规模化跑批待行。

## 度量口径

| 指标 | 口径 |
|---|---|
| 完成率 | 任务验收清单全过 = 完成；任一不过 = 未完成 |
| 一次绿灯率 | 首次构建即全绿的比例（不允许迭代修复后再计） |
| 时长 | 从交底到首次提交验收的墙钟时间 |
| 歧义点 | 执行中「文档说不清、需要猜」的位置清单——每个歧义点都是框架/文档的改进工单 |

## 怎么跑一条任务

1. 给一个「全新 agent」：任务卡（`tasks/` 下）+ 本仓库只读访问；工作目录在仓库之外；
2. 按任务卡的「允许阅读」清单执行，不得阅读 `eval/reference/**`；
3. 按任务卡验收命令跑结果，登记上述四类数字。
